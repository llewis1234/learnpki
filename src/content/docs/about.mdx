Certificates quietly hold the internet together, yet most people only meet them as a confusing error message. {SITE_NAME} is a place for anyone curious about certificate technologies to learn how they really work.

Every module pairs a plain explanation with something you build yourself using free, open-source tools. No sign-up, no paywall, no tracking.

{SITE_NAME} is an independent project. It is not affiliated with or endorsed by Smallstep, FreeRADIUS or nginx.
